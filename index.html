./vlie

A headless, multi-language semantic platform for the JVM.
Single static binary. Zero JVM dependency at runtime.

Code intelligence, deterministic analysis, and semantics-aware transformations.
Three interfaces, one engine: CLI (pipelines), LSP (editors), MCP (AI agents).

Written in Rust. Extensible via Starlark.
